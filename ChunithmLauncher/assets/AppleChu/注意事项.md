# 注意事项

`` 不需要使用 segatools 了 ``

## 关于手台io

如果用 chuniio 手台 dll 的，请同时在 applechu.toml 里面写 chuniio 的 path

下面这个地方：
```toml
## 外部 ChuniIO DLL
[ChuniIo]
## 所有架构共用的 DLL 路径
path = ""
```
## 关于读卡器

- 如果是串口读卡器，请在 applechu.toml 里面修改
```toml
[Aime]
enable = false
## 同时清空或关闭 AimeIO
[AimeIo]
enable = false
path = ""
```
- 如果是 aimeio 的读卡器，请在 applechu.toml 里面写 aimeio 的 path
```toml
[Aime]
enable = true

[AimeIo]
enable = true
path = ""
```
 
## 独占/8ch
如果要开独占和/或 8ch，请把以下两行 enable = false 或者删掉
```toml
[ForceSharedAudio]
enable = false

[Force2chAudio]
enable = false
```
