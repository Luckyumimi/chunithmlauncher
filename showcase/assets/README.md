# Showcase Assets

These images are rendered from the local `thesis-features` checkout for the independent project showcase.

- `screenshots/ui-*.png` are captured from `ui/index.html` at the launcher window size `1280×820`, using the light theme.
- `screenshots/ui-home-resolution-panel.png` is a crop of the real home screenshot showing the resolution controls and launch action.

The showcase page is independent from the Windows launcher's `ui/` publish path.
